OptiGest

Toute la gestion de votre magasin d'optique, sur votre PC : clients, ordonnances, factures, mutuelles et rappels.

Télécharger l'installateur

Présentation du service

OptiGest est une application desktop Windows (données en local, SQLite). Un seul fichier d'installation : raccourci bureau, menu Démarrer, tout compris.

Clients + recherche

Fiches clients, téléphone, mutuelle, historique complet.

Ordonnances

Historique optique OD/OG, dates, notes — plus de cahier papier.

Devis & factures

Lignes, totaux en DH, impression PDF.

Mutuelles

Suivi CNOPS / CNSS : dépôt, montant, statut.

Rappels WhatsApp / SMS

Liste des rappels + ouverture directe WhatsApp ou SMS.

Articles

Catalogue magasin : montures, verres, lentilles, accessoires.

Tableau de bord

Vue d'ensemble du travail du jour et des dossiers en cours.

Paramètres magasin

Nom, adresse, téléphone et ICE sur les PDF. Changement de mot de passe.

Prérequis

Windows 10/11 64 bits, ou macOS 12+ (Intel ou Apple Silicon). Tout est inclus dans l'installateur : aucune installation supplémentaire.

Guide d'utilisation

Parcours complet, de l'installation jusqu'aux factures PDF et aux rappels WhatsApp.

1. Installation

Windows

  1. Téléchargez OptiGest pour Windows (OptiGest-Setup.exe).
  2. Double-cliquez. Si Windows affiche un avertissement, choisissez Exécuter quand même.
  3. Suivez l'assistant (raccourci bureau, menu Démarrer).
  4. Lancez OptiGest. La première ouverture peut prendre quelques secondes.

Mac (macOS 12 ou plus)

  1. Téléchargez OptiGest pour Mac : Apple Silicon (M1/M2/M3/M4) = arm64, Intel = x64.
  2. Ouvrez le .zip, glissez OptiGest.app dans le dossier Applications.
  3. Au premier lancement : clic droit sur l'app → Ouvrir (l'app n'est pas signée Apple). Si macOS bloque encore : Réglages Système → Confidentialité et sécurité → Ouvrir quand même.
  4. En terminal, si besoin : xattr -cr /Applications/OptiGest.app puis relancez.

2. Connexion

  1. À l'écran d'accueil, saisissez l'email et le mot de passe fournis à la livraison (ils ne sont pas publiés ici).
  2. Cliquez sur Se connecter.
  3. Dès la première session, allez dans Paramètres et changez le mot de passe.

Si la session expire, reconnectez-vous avec le même compte. Le bouton Déconnexion se trouve en bas du menu gauche.

3. Menu et tableau de bord

Le menu de gauche donne accès à toutes les fonctions : Tableau de bord, Clients, Ordonnances, Devis, Factures, Articles, Mutuelles, Rappels, Paramètres.

Le tableau de bord affiche en un coup d'œil :

  • le nombre de clients ;
  • les devis ouverts ;
  • les rappels dus ;
  • les dossiers mutuelle en cours ;
  • les factures du mois et le chiffre d'affaires (TTC) ;
  • les derniers clients et les prochains rappels.

Cliquez sur une carte pour ouvrir la page correspondante.

4. Clients

  1. Menu Clients → Nouveau client.
  2. Renseignez au minimum le nom. Ajoutez prénom, téléphone, email, adresse, CIN, date de naissance, type de mutuelle (CNOPS, CNSS, autre) et des notes si besoin.
  3. Enregistrez. Une référence client est créée automatiquement.

Dans la liste, utilisez la recherche (nom, prénom, téléphone, référence). Cliquez un client pour ouvrir sa fiche : historique des ordonnances, documents et mutuelles. Le crayon permet de modifier, la fiche téléphone d'appeler ou d'écrire.

5. Ordonnances

  1. Ouvrez un client, ou le menu Ordonnances → nouvelle ordonnance.
  2. Choisissez le client et la date.
  3. Saisissez l'œil droit (OD) et l'œil gauche (OG) : sphère, cylindre, axe, addition.
  4. Complétez l'écart pupillaire (PD), le type de verre, le médecin et les notes.
  5. Enregistrez. L'historique reste sur la fiche client : plus besoin de cahier papier.

6. Devis et factures

Le principe est le même pour un devis et une facture.

  1. Menu Devis ou Factures → Nouveau.
  2. Sélectionnez le client, la date et le statut (brouillon, envoyé, accepté, payé, annulé).
  3. Ajoutez des lignes : désignation, quantité, prix unitaire (DH). Le bouton Ligne ajoute une ligne ; la corbeille la supprime.
  4. Les totaux HT, TVA 20 % et TTC se calculent tout seuls.
  5. Enregistrez, puis cliquez sur PDF pour télécharger / imprimer le document.

Le PDF reprend le nom du magasin, l'adresse, le téléphone et l'ICE définis dans Paramètres. Vous pouvez aussi générer le PDF depuis la liste (icône téléchargement).

7. Articles (catalogue)

  1. Menu Articles → ajouter un produit.
  2. Indiquez le titre, le prix, la catégorie (montures, verres, lentilles, solaires, accessoires…), une description et éventuellement une image.
  3. Décochez « publié » pour masquer un article sans le supprimer.

Ces articles servent de catalogue interne : vous pouvez reprendre les libellés et prix dans les lignes de devis / facture.

8. Mutuelles (CNOPS / CNSS)

  1. Menu Mutuelles → nouveau dossier.
  2. Choisissez le client, l'organisme (CNOPS, CNSS, autre), la référence, la date de dépôt et le montant.
  3. Suivez le statut (en cours, accepté, refusé, payé) et ajoutez des notes.

Le tableau de bord rappelle combien de dossiers sont encore en cours.

9. Rappels WhatsApp / SMS

  1. Menu Rappels → nouveau rappel.
  2. Choisissez le client : le téléphone et un message type se remplissent si le numéro existe sur la fiche.
  3. Fixez la date prévue et le canal : WhatsApp, SMS, ou les deux.
  4. Enregistrez. Quand le rappel est dû, cliquez l'icône WhatsApp (ouvre wa.me) ou SMS (ouvre l'application SMS de Windows).

Marquez le rappel comme envoyé / terminé une fois le client contacté. Les rappels dus apparaissent aussi sur le tableau de bord.

10. Paramètres et mot de passe

Menu Paramètres, deux blocs :

  • Magasin : nom, adresse, téléphone, email, ICE, TVA par défaut. Ces infos s'impriment sur les PDF. Cliquez Enregistrer.
  • Mot de passe : mot de passe actuel, nouveau mot de passe (6 caractères minimum), confirmation. Cliquez Changer le mot de passe.

11. Données, sauvegarde et dépannage

  • Tout est local sur le PC (fichier SQLite). Aucune donnée n'est envoyée sur internet, sauf WhatsApp / SMS que vous ouvrez vous-même.
  • Pour sauvegarder : copiez le dossier %AppData%\OptiGest (base optigest.db) vers une clé USB ou un disque.
  • Si l'app affiche « Impossible de démarrer le service local » : fermez OptiGest, attendez 3 secondes, relancez. Ne lancez pas deux fois l'application en même temps.
  • Pour réinstaller : désinstallez OptiGest, téléchargez à nouveau l'installateur, réinstallez. La base dans AppData est en général conservée.
